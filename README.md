# CodePulse

CodePulse 是 monorepo，包含两个同级的独立功能包：

| 包 | 功能 | 入口 |
| --- | --- | --- |
| `packages/vscode` | VS Code 插件：按项目汇总查看编码时间 | [packages/vscode/README.md](packages/vscode/README.md) |
| `packages/codepulse` | 终端编码时间采集：CLI + zsh 插件 | [packages/codepulse/README.md](packages/codepulse/README.md) |

## 需求文档

详见 [docs/spec.md](docs/spec.md)。
